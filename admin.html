الدخول (مرة وحدة فقط)
📖 كيفاش نجيب الرمز (Token)؟ 1. افتحي GitHub ← صورتك ← Settings
2. في الأسفل: Developer settings ← Personal access tokens ← Fine-grained tokens
3. Generate new token وسميه مثلا: store
4. Repository access ← Only select repositories ← اختاري مستودع المتجر
5. Permissions ← Repository permissions ← Contents: Read and write
6. Generate token وانسخي الرمز وألصقيه فوق.
الرمز يتحفظ في هذا المتصفح فقط. لا تشاركيه مع أحد.
